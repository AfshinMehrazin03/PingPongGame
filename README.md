# 🏓 Ping Pong Game

یک بازی ساده پینگ پونگ دو نفره ساخته شده با Unity

## فایل‌ها
- `PaddleController.cs` - کنترل حرکت راکت‌ها
- `BallController.cs` - حرکت توپ و تشخیص گل
- `GameManager.cs` - مدیریت امتیازات و پایان بازی
- `ScoreManager.cs` - نمایش امتیازات روی صفحه

## نحوه بازی
- **راکت چپ**: W (بالا) و S (پایین)
- **راکت راست**: کلیدهای بالا و پایین
- **R**: restart بازی

## تنظیمات در یونیتی
- به راکت چپ تگ "Paddle" بدهید
- به دروازه چپ تگ "LeftGoal" بدهید
- به دروازه راست تگ "RightGoal" بدهید
